# GoldHEN PS4 Jailbreak

A GoldHEN-focused version of this PS4 jailbreak project.

## Included

- Web entry point: `index.html`
- Jailbreak page: `jb.html`
- Jailbreak logic: `jb.js`
- Firmware/offset data: `ps4_offsets.js`
- Kernel patch files: `patches/`
- Bundled GoldHEN payload: `GoldHen.bin`

## Payload

This repository includes a local `GoldHen.bin` payload for the GoldHEN version of the project.

The existing jailbreak code and firmware tables are kept intact rather than presenting the repository as a generic archive.

## Notes

Use only with hardware and software you own or are authorized to modify.

GoldHEN and the underlying jailbreak components are the work of their respective authors. This repository packages them as a GoldHEN-focused web project.
